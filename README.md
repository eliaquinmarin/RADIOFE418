readme_content = """# 📻 Radio FE 4:18 | Radio Cristiana en Vivo

¡Bienvenido al repositorio oficial de **Radio FE 4:18**, una aplicación web moderna e interactiva diseñada para transmitir radio cristiana en alta fidelidad las 24 horas del día, los 7 días de la semana! Transmitiendo mensajes de fe, oración y la mejor programación musical desde **Barinas, Venezuela**.

Esta plataforma ha sido desarrollada con un enfoque de alto rendimiento, optimización móvil como PWA (Progressive Web App) y un diseño de interfaz de usuario espectacular basado en esquemas modernos como el *Glassmorphism*.

---

## ✨ Características Principales

* 🔊 **Reproductor de Alta Fidelidad (24/7):** Streaming de audio continuo y estable con control de volumen integrado.
* 🌓 **Soporte de Modo Oscuro Nativo:** Sistema que detecta la preferencia del sistema operativo o guarda la elección del usuario de forma local (*localStorage*).
* 📊 **Metadatos en Tiempo Real (SonicPanel API Ready):** Muestra el título de la canción, el artista actual y el conteo dinámico de oyentes en vivo.
* 🎵 **Top 5 Musical Automatizado:** Sección interactiva para visualizar las canciones cristianas más destacadas del mes (como Forrest Frank, Christine D'Clario, entre otros) con enlaces directos a Spotify y Apple Music.
* 📺 **Playlists de YouTube Recomendadas:** Integración fluida de listas de reproducción y programas especiales (*Lazos de Vida*, *Reflexiones Diarias*, *Hogares de Roca*).
* 📅 **Módulo de Programación:** Estructura interactiva basada en pestañas dinámicas para organizar y revisar los segmentos y horarios de transmisión.
* 💬 **Interactividad Directa (WhatsApp API):** Accesos rápidos para pedir oración, enviar saludos de voz o solicitar una canción directamente a cabina.
* 📱 **PWA Integrada:** Preparada con `manifest.json`, iconos adaptativos y lista para ser instalada directamente en dispositivos Android, iOS o PC.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 & CSS3:** Semántica web moderna y hojas de estilo optimizadas.
* **Tailwind CSS (Vía CDN):** Configuración personalizada con variables de diseño propias de la marca (`brand-neon`, `brand-neonPink`, `brand-card`).
* **JavaScript (Vanilla ES6):** Manejo fluido del DOM, control de eventos para el reproductor de audio, persistencia de temas y consumo de servicios dinámicos.
* **Font Awesome v6.4.0:** Set completo de iconos vectoriales para una navegación intuitiva y limpia.
* **Canvas API (Visualizer):** Renderizado en tiempo real de componentes gráficos para acompañar la sintonía.

---

## 🎨 Paleta de Colores Corporativa

La aplicación utiliza variables personalizadas extendidas mediante Tailwind CSS:

* `brand-dark`: `#09090b` (Fondo principal en modo oscuro)
* `brand-card`: `#18181b` (Contenedores y tarjetas oscuras con efecto cristalizado)
* `brand-lightBg`: `#f4f4f5` (Fondo claro y limpio)
* `brand-neon`: `#06b6d4` (Azul cian brillante para acentos de reproducción y conteo)
* `brand-neonPink`: `#ec4899` (Rosa magenta para el área de programación y donaciones)
